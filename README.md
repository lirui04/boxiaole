# 伯小乐组合包定价工具

> 腾讯蓝领招聘 58同城/赶集直招 双模式组合包定价计算器 & 智能对比分析工具

**当前版本：V4.1**

---

## 项目简介

伯小乐组合包定价工具是一款单文件 Web 应用，用于 **58同城** 和 **赶集直招** 两大招聘平台的伯小乐/职小乐组合包定价计算与智能对比分析。

核心能力：
- 📊 自动计算组合包的总刊例价、套餐售价、折扣率、活动价
- 🔄 支持 58 同城 / 赶集直招 双模式一键切换
- 🔗 SKU 单品刊例价联动管理
- 📋 刊例价披露表自动生成与导出
- 🧠 智能定价分析：优势/劣势/倒挂检测 + 调整建议
- 📤 支持 Excel 上传更新数据

---

## 功能特性

### 1. 双模式定价计算
- **58同城模式**（10 个套餐区，32 个组合包）
- **赶集直招模式**（6 个套餐区，21 个组合包）
- 每个组合包自动计算：
  - `I 总刊例价` = Σ(各权益数量 × 各权益刊例价基数)
  - `J 套餐售价` = ROUNDUP(I/C数量, -2)
  - `K 套餐折扣率` = J×C / I
  - `M 活动价` = 换购 ? J : ROUND(J/0.6, -2)

### 2. SKU 单品刊例价管理
- 完整的 SKU 数据库（编号、全称、产品类型、售卖时间、刊例价）
- 支持新增 SKU、修改刊例价（V3.9 起现有 SKU 只读，新增行可全编辑）
- 产品类型多选 + 关键词搜索筛选器（V4.0）

### 3. 套餐区 SKU 联动
- 每个套餐区 C/D/E/F/G/H 权益可绑定对应 SKU
- 刊例价基数自动从 SKU 数据库调取
- D 列「劲爆职位」自动识别资源/容器类型（V4.1）

### 4. 刊例价披露表
- 一键生成对客披露表格
- 字段：商品名称、时长、伯小乐权益（含数量）、售价、刊例价、发布限制
- 商品名称多选+关键词筛选器（V4.1）
- 支持 CSV 导出

### 5. 智能对比分析
- 基准包 vs 对比包的并排定价对比
- 自动检测：倒挂风险、折扣率异常、日均价合理性
- 每条问题给出具体调整建议
- 整体健康评级（健康/⚠️/🚨）

### 6. 数据管理
- Excel 上传更新（支持同步套餐数据和 SKU 数据）
- CSV 导出完整定价明细
- 行内编辑（点击 ✎ 进入编辑模式）

## 使用方法

### 快速启动
直接用浏览器打开 `伯小乐组合包定价工具.html` 即可使用。

### 操作指南
1. **切换模式**：点击顶部「58 同城」/「赶集直招」标签
2. **查看/编辑组合包**：点击行内 ✎ 按钮进入编辑模式
3. **管理 SKU**：点击「SKU 单品刊例价」查看/编辑
4. **关联 SKU**：点击「伯小乐套餐区管理」为权益绑定 SKU
5. **对比分析**：新增/修改组合包后点击「对比定价选择」
6. **刊例价披露**：点击「刊例价披露」一键生成对客表格
7. **更新数据**：点击「上传更新Excel」导入 Excel 数据
8. **导出**：点击「导出数据」下载完整 CSV

### 技术栈
- 纯前端 HTML/CSS/JavaScript（单文件，零依赖）
- SheetJS (CDN) — 浏览器端 Excel 解析
- Python (openpyxl) — 辅助数据提取脚本
